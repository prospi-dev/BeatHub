# BeatHub — Frontend

React 19 + Vite SPA for BeatHub. See the [root README](../../README.md) for the full project overview, architecture, and setup instructions (backend + frontend).

## Quick start

```bash
npm install
npm run dev
```

Requires a `.env` with:
```env
VITE_API_URL=https://localhost:7117/api
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
